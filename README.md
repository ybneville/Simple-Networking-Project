
# Small Office Network - Packet Tracer

## Overview
This project simulates a small office network using Cisco Packet Tracer.

## Features
- Static IP addressing
- DHCP configuration
- VLAN segmentation
- Inter-VLAN routing

## Devices Used
- 1 Router
- 1 Switch
- 5 PCs

## How to Run
Open the .pkt file using Cisco Packet Tracer.
